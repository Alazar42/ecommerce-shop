# Micky's Shop — eCommerce Demo

A modern eCommerce test project built with **Next.js**, **TypeScript**, **Tailwind CSS**, **ShadCN UI**, **Redux Toolkit**, and **DummyJSON API**.
This project includes CRUD functionality, theme switching, toast notifications, smooth loading states, and optimized UX.

---

##  Features

*  **Next.js App Router**
*  **Light & Dark Theme** (Redux + ShadCN)
*  **CRUD for Products**
*  **DummyJSON API Integration**
*  **Sonner Notifications**
*  **Skeleton Loaders**
*  **Lazy Loading**
*  **Search Products**
*  **Fully Responsive UI**

---

## 📦 Installation & Setup (using npm)

### 1. Clone the repository

```bash
git clone https://github.com/Alazar42/ecommerce-shop.git
cd ecommerce-shop
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

The app will now be available at:

```
http://localhost:3000
```

---

## 🏗️ Build for production

```bash
npm run build
```

Preview the production build:

```bash
npm start
```
